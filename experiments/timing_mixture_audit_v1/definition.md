# Timing-mixture audit v1 — exploratory accounting, not a new gate

The completed intervention-timing study is already unblinded and closed
NO-GO. Dense right-veer AUC fell in all three seeds while geometric ranking
improved. Freeze this diagnostic before reading timing-stratified scores.
It cannot establish a new prospective performance result or reopen that gate.

Question: within each of the four original primary action cells, is the
pooled AUC change associated with ranking inside an exam-timing block, ranking
between blocks, or both? Use all six saved score exports and the exact common
exam metadata, seeds 0/1/2, warn horizon 32. Examine all four original cells
(dense/moving × left/right), not only the unfavorable cell.

For each model/cell, partition positive×negative score pairs by the source
course's saved `study_timing_block`: approach (0) and immediate (1). Report
both within-block AUCs and all four positive-block/negative-block pair AUCs,
pair counts, weights and additive contributions to the original pooled AUC.
Subtract matched arms at each seed, retaining within-block and cross-block
contribution deltas. Their sum must reconstruct every original action-cell
delta to absolute tolerance 1e-12. Also reconstruct the original four-cell
macro for every seed and preserve the original NO-GO unchanged.

Record both label window counts and distinct course counts for each cell/
block. Annotate whether each block meets the original exam's 100 windows /
ten courses per class floors, strictly as a descriptive support annotation;
this neither adds a new gate nor changes an old one. Missing-class AUC is
null, never the legacy 0.5 fallback. No speed, position, score-threshold or
additional action slicing is permitted in this diagnostic. No new inference,
training, generation, resampling, sample selection, bootstrap or seed search.

Validate all saved hashes, sample/label/world/action identities, complete
exam coverage, block membership/size and receipt metadata before accounting.
Keep original course IDs and overlapping windows. Pair weights are counts
of score comparisons, not independent trials; courses can contribute both
classes. Blocks use distinct simulator seeds as registered, so differences
between blocks also contain draw variation. Timing-conditional patterns
cannot identify a training mechanism, causal timing effect or flight safety.

The original common-exam support and rendering receipts remain the evidence
for those instruments. This audit is metadata/score-only and reads no pixels
or checkpoint weights. Bind its new code plus the original source/input
identities and all nine locked artifacts before measurement. Archive every
cell/seed, including negatives, with a rerunnable verifier. Close after this
single fixed analysis; no interpretation releases a new fit or changes the
approach default.
